# Release checklist

- [x] Confirm author metadata and `CITATION.cff`.
- [x] Confirm repository owner and repository URL metadata.
- [x] Confirm and add the repository-code license.
- [ ] Run the deterministic test suite and smoke workflow.
- [ ] Review the intended public files and example outputs.
- [ ] Confirm that scientific binaries, experimental inputs, databases, and runtime work directories are excluded.
- [ ] Initialize version control and inspect the initial file set.
- [ ] Create one initial release commit.
- [ ] Create the public repository and publish the main branch.
- [ ] Verify README links, Mermaid rendering, example figures, citation metadata, and release version on the public page.
